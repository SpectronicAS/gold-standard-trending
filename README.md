# gold-standard-trending
Gold Standard Trending is a python applicaion for generating and tracking calibration certificates for NorthStar Scientific BIO-UVs.
## User Guide
To use, first open the executable file. Once open select "add calibration" and use the file browsers to locate the scans taken from the BIO-UV and click OK.

The values should then be displayed on the graph for the mean, variance and standard deviation.

Calibrations can be deleted by selecting from the list on the left and pressing "Delete Calibration"
